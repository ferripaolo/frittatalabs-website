Clockwork

Protocol-powered Clojure runtime on iOS

Clockwork is a faithful Clojure implementation built from first principles in Swift. It runs a live REPL on iOS with seamless namespace hydration from Git, hot-swappable evaluation strategies, and macro expansion as a service.

Core capabilities

  • Pluggable evaluation: Swap evaluators mid-execution for tracing, experimentation, or performance tuning.
  • Remote namespace hydration: Load Clojure code from Git or remote sources directly into the running runtime.
  • Macro expansion server: Expansion as a service—trace, inspect, and understand how your code transforms.
  • Live REPL on iOS: Iterate on UI and logic at the speed of thought. No reload, no rebuild.
  • Full evaluator, compiler, pretty printer: Everything you need to run real Clojure, nowhere else runs it.
GitHub Watch the talk

Why this matters

Most runtimes are sealed boxes. You can run code, but you can't inspect or swap the machinery. Clockwork rethinks that—evaluation is a protocol, not a black box. This enables something unprecedented: a language as dynamic as Clojure, running on iOS, with the ability to iterate on live UI at the speed of thought.

It's a proof point that clarity and composability aren't luxuries. They're the foundation of systems that move.
